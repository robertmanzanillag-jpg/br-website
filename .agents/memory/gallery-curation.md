---
name: Gallery duplicate evidence
description: How to make safe, presentation-only media exclusions when filenames repeat.
---

Treat a repeated filename as a candidate, not proof of a duplicate. Different source IDs and different capture timestamps can belong to distinct photos even when filenames match. Keep ambiguous items visible until visual or file evidence confirms duplication. Explicit numbered export variants can be hidden when the unsuffixed version exists in the same collection and media type.

**Why:** An audit of gallery entries found identical file copies as well as same-name images with different previews and capture times. Removing every repeated title would hide distinct photos.

**How to apply:** Keep curation in the separate presentation-only exclusion manifest. Never rewrite source catalog URLs or alter files in Drive/Zoho. Scope exclusions to the same collection and retain ambiguous matches.
