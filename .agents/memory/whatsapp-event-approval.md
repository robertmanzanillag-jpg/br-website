---
name: WhatsApp event approval
description: Scope boundary for turning WhatsApp flyer or price messages into production event updates.
---

Do not update production events or prices from WhatsApp intake until the source message is matched to the exact event and that match is verified.

**Why:** Similar event names, flyers, and dates can refer to different events; an incorrect match would alter production data.

**How to apply:** Keep extracted WhatsApp changes pending review until a human confirms the event correspondence. Never write automatically based only on text or flyer similarity.
